# 收工未？ (SauGungMei)

> 專為香港打工仔：Part-time、炒散及打造嘅「薪金計算同與心理慰藉神器」

---

## 💡 產品簡介

每日返工最關心嘅兩件事：「仲有幾耐放工？」同埋「呢刻賺咗幾多錢？」。

**「收工未？」** 將枯燥嘅工時倒數轉化為**即時跳動嘅薪酬看板**，令每秒嘅付出即時睇得到回報。程式亦提供返工交通飲食開銷扣除、離座「白賺」統計以及一鍵隱私遮蔽功能，為忙碌嘅打工生活增添少少情緒價值與實用性。

---

## ✨ 核心功能

* ⏱️ **秒級跳動工資看板**
  * 支援「時薪制」與「日薪制」自動換算。
  * 動態圓形進度條即時倒數放工時間，清晰展示「呢刻賺咗」與「今日總計」。
  * 支援自訂用餐扣除分鐘（工時比例平攤機制，避免開工初段收益歸零）。

* 🚽 **「蛇王／廁所 Break」白賺計時器**
  * 獨立紀錄離座放空時間。
  * 按照當前有效時薪，實時計算公司喺你離座期間「照出畀你嘅薪金」，清楚掌握自己今日「白賺」咗幾多。

* 💸 **返工成本開支與「真．淨時薪」**
  * 自由新增開銷明細（如來回車費、外賣午餐、咖啡等）。
  * 自動由總薪金扣除開銷，計算「扣除成本淨賺」及實質之「新平均時薪」。

* 🚀 **開工核對與工作備註**
  * 每日開工前彈窗快速核對時間與薪酬設定，避免手誤。
  * 支援自訂「工作名稱／備註」（如：兼職咖啡師、設計 Freelance、零售店務），方便多工族分類紀錄。

* 📑 **完整收工歷史紀錄**
  * 點擊收工後自動儲存完整明細。
  * 卡片支援點擊展開，即時查看工時、蛇王白賺金額、開銷清單與實質淨時薪。
  * 支援隨時修改歷史紀錄之工作備註，並具備防誤觸刪除確認機制。

* 🔒 **極致隱私保護與純本地運作**
  * 一鍵金額隱藏模式（切換為 `••••`），保護薪酬隱私。
  * **無後端伺服器架構**：所有數據只存放喺使用者本地瀏覽器（LocalStorage），無資料外洩風險。
  * 支援完整 JSON 格式備份匯出與還原。

* 📱 **PWA 支援與離線快取**
  * 支援安裝至手機主畫面，提供接近原生 App 嘅全螢幕體驗。
  * 內置 Service Worker 離線存取與 GitHub 最新版本更新偵測。

## 🛠️ 技術架構

* **Core Framework**: [Vue 3](https://vuejs.org/) (Composition API，CDN 極簡引入架構)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) + CSS 變數（語義化類別，支援全域深色／淺色主題切換）
* **Storage**: Browser LocalStorage（本地無伺服器存儲）
* **PWA Engine**: Service Worker + Web App Manifest（支援離線運作與自動更新快取）
